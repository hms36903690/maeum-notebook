# 마음 공책

질문을 따라 쓰는 나만의 마음 일기 앱입니다. 휴대폰 홈 화면에 깔아서 씁니다.
운휘 타로, 영업비서와 상관없는 단독 앱입니다.

## 나만 쓰는 방법

- 처음 열 때 정한 **비밀번호**가 있어야 열립니다. 5분 동안 손대지 않으면 다시 잠깁니다.
- 기록은 그 비밀번호로 **암호화**되어 **휴대폰 안에만** 저장됩니다. 인터넷 어디에도 보내지 않습니다.
- 사이트 주소를 다른 사람이 알아도, 그 사람 휴대폰에는 빈 공책만 열립니다.
- 비밀번호를 잊으면 기록을 되살릴 수 없습니다.

## 휴대폰에 설치하기

1. 휴대폰 크롬으로 이 앱의 주소(예: `https://아이디.github.io/maeum-notebook/`)를 엽니다.
2. 비밀번호를 정합니다.
3. 화면 아래의 **홈 화면에 앱으로 설치** 버튼을 누르거나, 크롬 메뉴(⋮) → **홈 화면에 추가** / **앱 설치**를 누릅니다.
4. 이제 홈 화면의 마음 공책 아이콘으로 엽니다. 인터넷이 없어도 열립니다.

## 휴대폰과 태블릿에서 같이 쓰기

1. 먼저 쓰던 기기에서 **책장 → 기기 연결**로 들어가요.
2. 안내대로 GitHub 열쇠(토큰)를 만들어 붙여 넣고 **연결하기**를 눌러요.
   (Expiration은 No expiration, 권한은 gist만 있으면 돼요.)
3. 태블릿 크롬으로 같은 주소를 열고, 첫 화면의 **다른 기기에서 쓰던 공책 이어 쓰기**를 눌러요.
4. 같은 GitHub 열쇠를 넣고, 같은 비밀번호로 열어요.

이후에는 쓰면 몇 초 뒤 자동으로 올라가고, 앱을 열 때와 1분마다 다른 기기 것을 받아 와요.
GitHub에는 비밀번호로 암호화된 상자만 올라가서 GitHub도 내용을 읽을 수 없어요.
한 기기에서 비밀번호를 바꾸면, 다른 기기는 다음에 맞출 때 새 비밀번호를 물어봐요.

## 백업

휴대폰을 바꾸거나 앱(크롬 데이터)을 지우면 기록도 사라집니다.

- **책장 → 백업 파일 저장**: 암호화된 백업 파일이 다운로드 폴더에 저장됩니다. 구글 드라이브 등에 올려 두면 안전합니다.
- **새 휴대폰**: 앱을 연 뒤 첫 화면의 **백업 파일로 시작하기** → 파일 선택 → 백업할 때의 비밀번호로 엽니다.

## 메뉴

- **대화하기**: 쓰기 카드 7개 (감사 세 줄 · 나에게 묻고 답하기 · 미래의 내가 나에게 쓰는 편지 · 걱정 내려놓기 · 네 가지 질문 · 현실 창조 10단계 · 숨은 믿음 찾기)
- **나의 지도**: 목표와 매일 할 일을 체크하면 나무에 잎이 돋습니다.
- **같이해요**: 오늘 한 일을 한 줄로 남깁니다.
- **일정**: 기록한 날에 점이 찍히는 달력입니다.
- **책장**: 지난 기록 보기, 잠그기, 백업, 비밀번호 바꾸기.

## 인터넷에 올리기 (GitHub Pages, 무료)

1. GitHub에서 새 저장소 `maeum-notebook`을 만들고 이 폴더의 파일을 올립니다.
2. 저장소 **Settings → Pages** 에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 정하고 Save.
3. 1~2분 뒤 `https://아이디.github.io/maeum-notebook/` 에서 열립니다.

무료 GitHub Pages는 저장소가 공개(public)여야 합니다. 공개되는 것은 앱 코드뿐이고, 기록은 각자의 휴대폰에만 있습니다.

## 고친 뒤 휴대폰에 반영하기

`index.html`을 고쳐 올린 뒤에는 `sw.js` 맨 위의 `maeum-notebook-v1` 숫자를 하나 올려 주세요(v2, v3…). 앱을 한 번 닫았다 열면 새 버전이 적용됩니다.

## 컴퓨터에서 미리 보기

```bash
npx serve -l 5180 .
```
그리고 브라우저에서 http://localhost:5180 을 엽니다.
